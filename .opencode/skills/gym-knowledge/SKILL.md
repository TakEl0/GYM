# Habilidad: Dominio de Gimnasio y Entrenamiento (GYM)

Asignada a `subagente-dominio`:

1. **Fórmulas de 1RM**:
   - **Epley**: `1RM = W * (1 + r / 30)`
   - **Brzycki**: `1RM = W * (36 / (37 - r))`
   *(Donde `W` es el peso levantado y `r` el número de repeticiones efectivas).*

2. **Distribución de Volumen Semanal Recomendado**:
   - **Principiante**: 10-12 series efectivas por grupo muscular / semana.
   - **Intermedio / Avanzado**: 12-20 series efectivas por grupo muscular / semana.

3. **Sustitución de Maquinaria (Alternativas Inteligentes)**:
   - Si **Prensa de Piernas** no está disponible -> **Sentadilla Hack** o **Sentadilla Búlgara**.
   - Si **Jalón al Pecho** no está disponible -> **Dominadas asistidas** o **Remo en Polea Alta**.
   - Si **Extensiones de Cuádriceps** no están disponibles -> **Zancadas (Lunges)** o **Sentadilla Sissyp**.

4. **Taxonomía de Ejercicios y Constructor de Rutinas**:
   - Relación entre grupos musculares principales/secundarios y equipamiento (mancuernas, barra, polea, máquina guiada).
   - Diseños de rutinas clásicas: Push/Pull/Legs (PPL), Torso/Pierna y Fullbody.
